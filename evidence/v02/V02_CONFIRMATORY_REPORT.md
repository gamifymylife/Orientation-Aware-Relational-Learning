# Orientation-Aware Benchmark v0.2 — Frozen Held-Out Confirmatory Report

## Purpose

v0.2 tests whether the negative v0.1 smoke-test result was merely bad hyperparameter selection or whether the proposed stability/cost formulation fails to add value beyond generic OED over the same `(orientation, intervention)` action space.

The protocol is deliberately separated into:

`CALIBRATION SEEDS -> FREEZE lambda,gamma -> DISJOINT HELD-OUT TEST SEEDS`

No held-out result is used to select the frozen parameters.

## Methodological corrections from v0.1

1. **Failure-safe cost metric.** Raw cumulative cost is preserved, but failed runs no longer masquerade as low `C95`. `penalized_c95` adds a budget-equivalent penalty when the 0.95 posterior threshold is not reached.
2. **Hard reliability gate.** A calibration candidate is inadmissible if it loses more than 2 percentage points of 95%-identification success or final correctness relative to generic OED.
3. **Common random numbers.** Observation-noise streams are shared across policies. If two policies select the same experiments, they receive the same stochastic observations.
4. **Three explicit kill-controls.** `no_orientation_value`, `informative_unstable`, and `orientation_exclusive` are generated by construction and tested automatically.

## Calibration

Calibration uses seeds 0–23 only, across:

- standard clean;
- standard with perturbation 0.35;
- no-orientation-value control;
- informative-but-unstable control with perturbation 0.35.

Grid:

- `lambda_stability`: 0, 0.02, 0.05, 0.10, 0.20, 0.40
- `gamma_cost`: 0, 0.01, 0.03, 0.05, 0.10

Only **1 of 30** settings passed the hard reliability gate:

```text
lambda_stability = 0.0
gamma_cost       = 0.0
```

Therefore the frozen Full-OARL policy reduces exactly to generic OED.

This is the central v0.2 result: **the currently proposed stability and cost penalties do not survive reliability-constrained calibration.**

## Held-out evaluation

Five disjoint confirmatory blocks were run with 100 fresh seeds each, for 500 held-out worlds total:

1. standard clean;
2. standard misspecified/perturbed;
3. no orientation value;
4. informative but unstable;
5. orientation-exclusive distinctions.

Frozen Full OARL versus Generic OED:

| Condition | Median penalized C95 reduction | 95% bootstrap interval |
|---|---:|---:|
| Informative unstable | 0.0% | [0.0%, 0.0%] |
| No orientation value | 0.0% | [0.0%, 0.0%] |
| Orientation exclusive | 0.0% | [0.0%, 0.0%] |
| Standard clean | 0.0% | [0.0%, 0.0%] |
| Standard misspecified | 0.0% | [0.0%, 0.0%] |
| **All 500 pairs** | **0.0%** | **[0.0%, 0.0%]** |

This equality is not a statistical failure to detect a tiny effect. With frozen zero penalties and common random numbers, the two policies are algorithmically identical.

## What survives

The broader orientation thesis survives strongly in the controls:

- In `standard_clean`, fixed-orientation OED reaches 95% confidence in **0%** of 100 runs, while generic orientation-search OED reaches it in **86%** and is correct in **97%**.
- In `orientation_exclusive`, fixed OED reaches 95% confidence in **0%**, while orientation-search OED reaches **100%** success and **100%** correctness.
- In `informative_unstable`, fixed OED again reaches **0%** success, while orientation-search OED reaches **91%** success and **96%** correctness.
- In the `no_orientation_value` negative control, fixed and full-search methods have the same underlying likelihood geometry, as intended; orientation does not create a magical informational advantage.

Thus the evidence distinguishes two claims:

### Supported

**Boundary/orientation can contain mechanism-identifying information unavailable from a fixed boundary.** Including orientation in the experiment-search space can convert non-identifying problems into identifying ones.

### Not supported by v0.2

**The current OARL stability/cost scoring rule improves on generic Bayesian OED over the same `(orientation, intervention)` action space.** Under a reliability-constrained calibration protocol, the optimizer turns those additions off.

## Quadrature confirmation

A slower 16-point Gauss-Hermite mutual-information calculation was run on 40 additional held-out worlds (20 standard clean, 20 informative unstable). Frozen Full OARL and Generic OED remained exactly equal:

```text
median paired cost reduction = 0.0%
max absolute paired reduction = 0.0%
```

So the negative Gate-2 result is not caused by the fast proxy information-gain approximation.

## Scientific interpretation

v0.2 passes **Gate 1** and fails the current formulation of **Gate 2**:

- **Gate 1 — Does orientation add information? YES.**
- **Gate 2 — Does the proposed structure-aware scoring exploit it better than generic OED? NO, not in this formulation.**

The correct conclusion is not to abandon orientation-aware experimental design. It is to stop claiming that the present additive penalty

`IG - lambda*log(1+K) - gamma*C`

is the useful innovation.

The next theoretical question is sharper: can orientation structure (`D_R`, admissible transport/alignment, equivalence classes, stability as calibrated predictive risk rather than a static penalty) reduce search or improve reliability **without sacrificing mechanism recovery**?

That requires a new method, not retuning this one until it wins.
